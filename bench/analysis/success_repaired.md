# Fresh-100 success under the repaired hallucination oracle (v3 candidate)

Generated by `bench/analysis/success_repaired.py`. The blinded validation
(`halluc_validation.md`) showed the raw oracle's *hallucinated* class has
13.3% precision, and `score_bridge.py` folds that raw flag into success as a
hard conjunct — with false flags hitting C/E far harder than D. This file
recomputes Tier-1 grounded-typecheck success with the 5-rule mechanically
repaired oracle (59/60 blinded agreement) and quantifies how every headline
contrast moves. Raw numbers are re-derived from `bridge_summary_v2.json` and
asserted against `part1_fresh100_v2.json` / `fresh_clustered.json`;
`bridge_summary_v2.json` itself is untouched.

Typecheck rig: `leanprover/lean4:v4.33.0-rc1`, mathlib `9944fe2973b8`
(the identical fresh-pin REPL pipeline that graded the Part-1 rows).

## EVAL-341: known limitation

Affected eval rows (produced ∧ no error ∧ raw-flagged ∧ repaired-clean): A 39, B 45, C 68, D 47, E 81 — 280 total, over the 150-row typecheck budget, so the EVAL-341 table is NOT
recomputed under the repaired instrument. These counts are hard upper
bounds on each arm's possible success gain there and must be disclosed
in the report: the same instrument bias direction (C/E flagged far more
than D) applies to the eval table.
